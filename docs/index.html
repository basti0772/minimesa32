Unterstützt: klassischer ESP32 / ESP32-WROOM-32 mit 4 MB Flash und der Projekt-Verdrahtung. Nicht für ESP32-S2, S3, C3 oder andere Chipfamilien.

  1. ESP32 mit einem USB-Datenkabel anschließen.
  2. Auf Install klicken.
  3. Den seriellen Port des ESP32 auswählen.
  4. Installation bestätigen und den Flash-Vorgang abwarten.
Vor dem Flashen

Die vorhandene Firmware wird ersetzt. Dieses zusammengeführte Image überschreibt auch NVS und damit gespeicherte Touch-Kalibrierungen – selbst ohne vollständiges Löschen des Flashs. Sichere wichtige Daten vorher. Ohne Kalibrierung verwendet die Demo ihre feste Standardzuordnung; diese passt nicht zu jedem Touchpanel.

Empfohlen: aktuelles Chrome oder Edge auf einem Desktop-PC. Web Serial benötigt HTTPS (lokal auch localhost). Seriellen Monitor und andere Programme schließen, die den Port belegen.

Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge auf einem Desktop-PC verwenden. Bitte diese Seite über HTTPS oder localhost öffnen. Firmware herunterladen ↓

Was läuft auf dem Board?

Ein kleiner OpenGL-artiger Renderer mit Z-Puffer, RGB565 und 1.024 Dreiecken. Acht Richtungstasten drehen die Teekanne in 45°-Schritten. Das ausgesparte Tastenfeld bleibt flackerfrei.

Verbindung klappt nicht?

Anderes Datenkabel oder USB-Port versuchen. Bei Bedarf den passenden USB-UART-Treiber für dein Board installieren. Falls der Bootloader nicht startet: BOOT gedrückt halten, Verbindung erneut starten und nach dem Verbindungsaufbau loslassen.

Alternative: Arduino CLI / manuelles Flashen. Nach der Installation startet die Animation automatisch.
